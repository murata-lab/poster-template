# poster-build: ポスターを HTML で組んで PDF にする

ポスターは `posters/<名前>/poster_en.html`・`poster_ja.html` が原稿で、`poster.css` がデザイン、`poster.js` が数式・QR コード・はみ出し検出を担う。ビルドのルールは `tools/poster.mk` に一箇所だけある。

## 1. 始める

```bash
make doctor                 # Chrome と poppler がそろっているか
make setup                  # Chrome がなければ（sudo 不要）
make new NAME=<名前>        # posters/_template をコピー
cd posters/<名前> && make watch
```

既存のポスターを直すなら、そのフォルダで `make watch` を起動するだけでよい。

## 2. 編集のたびに必ず確かめる

`make` の出力は 3 通りしかない。

| 出力 | 意味 | すること |
|---|---|---|
| `built poster_en.pdf (1 page)` | 収まっている | 見た目を確認する（下記） |
| `WARNING: ... overflows` | 本文か横幅がはみ出し、切り落とされている | §3 の順で直す |
| `WARNING: ... runs onto N pages` | ページ寸法と CSS が合っていない | `@page` と `--w`/`--h` をそろえる |

**「1 page」でも見た目は確かめる。** 数値の警告が出なくても、図が潰れる、段の最後が空く、帯のカードの高さがそろわない、といった崩れは起きる。

```bash
pdftoppm -png -r 50 -singlefile poster_en.pdf /tmp/look_en   # 画像にして全体を見る
```

エージェントは、この PNG を実際に開いて目で確認してから「できた」と報告すること。PDF ができたことだけを根拠にしない。

## 3. はみ出したときの直し方（この順で）

1. **文章を削る。** はみ出しの大半は文章の量が原因。poster-writing の語数の目安を見る。
2. **図を小さくする**、または図と文章を横に並べる（`.row`）。
3. **余白（section の margin、padding）を詰める。**
4. **最後に文字を小さくする。** A1 の本文は 18pt を下限とする（1〜2 m 離れて読める大きさ）。見出しや帯の文字は下げない。

赤い帯には、横にはみ出した要素の名前と先頭の文字列が出る。縦のはみ出しは右の段の最後が切れている。

## 4. CSS の直し方

- **既存の規則を書き換える。末尾に上書きを足さない。** `posters/iconip2026-lig/poster.css` は締切前に上書きを足し続けた結果、600 行近くになり、どの値が効いているか追えなくなった。同じセレクタがすでにあればそこを直す。
- 帯（`.band`）の図の幅は **mm で固定する**。% で指定すると、列の比率を変えたときに帯ごと膨らんで本文を押し出す。
- 英語版と日本語版で大きさを変えたいときは、`html[lang="ja"] …` のセレクタで上書きする。HTML 側に style を書かない。
- 色は `:root` の変数だけで変える。
- 段組みは CSS の `columns`。図・表・数式・段落は `break-inside: avoid` で段をまたがない。左段を下まで埋めてから右段に移したいときは `column-fill: auto` に変える。

## 5. 図

- 置き場所は `fig/`。ファイル名に空白を入れない（Makefile の依存関係が壊れる）。
- 解像度は印刷サイズで 200 dpi 以上（幅 250 mm の図ならおよそ 2000 px 以上）。matplotlib なら `savefig(..., dpi=300)`。
- SVG もそのまま `<img src="fig/x.svg">` で使える。ただし SVG の中の文字は、ビルドする PC のフォントで描かれる。`make check` を通すこと。

## 6. 英語版と日本語版

片方を原本と決め、そちらを先に直してからもう一方に反映する。反映したら両方を `make` し、両方の PNG を見る。日本語は同じ内容でも短くなりやすいので、日本語版だけ文字を少し大きくして空きを埋めてよい。

## 7. 紙のサイズ

`poster.css` の `@page { size: … }` と `--w` / `--h` を両方変える。A1 縦は 594×841 mm、A0 縦は 841×1189 mm。A0 にしたら pt で書いた文字の大きさをおよそ 1.4 倍にする。

## 8. 入稿前チェック

- [ ] `make` が英語版・日本語版とも `(1 page)` で、警告がない
- [ ] `make check` が `fonts OK (no Type 3)`。Type 3 は印刷所（特に布ポスター）で断られることがある。フォントを変えるなら静的な TrueType にする。可変フォント（Inter など）と CFF 形式（ローカルの Noto Sans CJK など）は Type 3 になる
- [ ] 全体を等倍近くまで拡大して、図の文字が読めるか・ぼやけていないかを見た
- [ ] QR コードを実機のスマホで読み取り、正しいページが開いた
- [ ] 著者名・所属・ポスター番号・謝辞（科研費番号）が最新
- [ ] 入稿先の指定（サイズ、塗り足し、ファイル形式、締切）を確認した

## 9. やってはいけないこと

- `tools/` のビルド手順を個別のポスターの Makefile にコピーしない（各ポスターの Makefile は `include ../../tools/poster.mk` の 1 行だけ）。
- `posters/_template/` を自分のポスターとして直接編集しない。`make new` でコピーしてから編集する。
- ビルドにはインターネット接続が要る（フォント・KaTeX・QR ライブラリを CDN から読む）。オフラインで PDF の文字化けや数式の未変換が起きたら、まず接続を疑う。
